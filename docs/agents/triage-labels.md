# Triage labels

Engineering skills use the following canonical label vocabulary.
The mapping is configuration only; the setup process does not create or modify labels on GitHub.

| Skill role | Repository label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the report |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | The work is specified for an implementation agent |
| `ready-for-human` | `ready-for-human` | The work requires a maintainer-controlled action |
| `wontfix` | `wontfix` | The repository will not pursue the request |

Only `wontfix` existed in the repository when this configuration was written.
Create the other labels only as part of an explicitly requested GitHub triage setup.
